# Docs

## 索引

| 文件 | 内容 |
|---|---|
| `build.md` | 构建 / 测试 / Benchmark 的操作方式 |
| `tasks/` | 每个 Task 的记录（用 `PROGRESS.md` 里的模板） |
| `reviews/` | Week / Month 复盘 |

## 目录约定

```text
Docs/
├─ build.md        构建说明
├─ tasks/          task01.md, task02.md, ...
└─ reviews/        week1_review.md, month1_review.md, ...
```

## 记录原则

- **Benchmark 必须有数字**：Workload / Hardware / Build / Before / After / Conclusion。
- **Task 记录落到文件**：做完一个 Task 就在 `tasks/` 留一份，方便回溯。
- **决策变更进 `DECISIONS.md`**，不在这里。
